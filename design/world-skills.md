## 一、地图扩展

### 现状

单一平地 2000×270（地面 y=238），两个 320×270 传送门房间（镇/洞），敌人一字排开。
没有平台、没有纵深、没有门控——不是银河恶魔城，是走廊。

### 目标布局（主世界扩至 ~6000px，五区，能力门控递进）

```
y=90   ·········································· [悟道崖] ← 飞行（缩地穿缝门控留待 blink 支持穿墙）
y=120           [青竹林·竹台]      [绝壁·顶]
y=160  ········  跳跃门控 ········  墙跳门控 ········
y=238 [落霞村外围]———[青竹林]———[断崖绝壁]———[幽谷]———[谷深处]
       x 0~1300    1300~2600   2600~3900   3900~5200  5200~6000
       凡人安全区   跳跃门控     墙跳门控     飞行门控    Boss+隐藏
```

| 区 | x 范围 | 门控 | 内容 |
|---|---|---|---|
| 落霞村外围 | 0~1300 | 无 | 现有内容（出生点/镇洞两门/赤瞳魔狼/凡级草药） |

| 断崖绝壁 | 2600~3900 | 墙跳（高墙 120px，两侧岩壁夹缝） | 垂直井道、弓手×2（岩台）、金刚藤×2（壁面）、落石近战×2、检查点 |

- **相机**：CameraRoom2D 跟随即可（无房间锁的世界段）；沟壑/绝壁段不设锁

## 三、被动技能体系（SkillSystem::TYPE_PASSIVE）

- **学会即常驻，不占槽**——与功法（1+1 双槽）的区别：被动是"悟得的诀窍"，永久生效可叠加；
  功法是"在修的功课"，换着修。数值走各自乘区，幅度小于功法（添头级 10~25%）
- Def 复用 Skill Def + 被动字段：passive_stat（atk/spd/def/mana_regen/fly_speed/law_regen）+ passive_value

| id | 名 | 效果 | 解锁 |
|---|---|---|---|
| jian_xin | 剑心通明 | 攻击+10% | 筑基 |
| shen_xing | 神行百变 | 移速+12% | 炼气 |
| tie_bu_shan | 铁布衫 | 防御+15% | 金丹 |
| ling_tai | 灵台清明 | 灵力回复+25% | 金丹 |
| feng_lei_yi | 风雷双翼 | 飞行速度+15% | 元婴 |
| dao_fa_zi_ran | 道法自然 | 法则回复+25% | 化神 |

挂钩点（与功法/法宝/buff 同乘区）：
- 攻→get_effective_attack；防→_take_damage_typed；速→_update_move_speed；飞速→PlayerFlyState top_speed
- 回灵→CultivationSystem.set_mana_regen_mult(功法×被动)；法则→新增 set_law_regen_mult
- 刷新：learn 时 emit skills_changed → Player._refresh_passive_hooks()
