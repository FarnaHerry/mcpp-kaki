## 一、体系总览（四阶金字塔）

```
第 1 阶  功法   —— 被动基础数值（炼体/练气，最多同修 1+1）
第 2 阶  技能   —— 武技（物理）/ 法术（灵力驱动）
第 3 阶  神通   —— 法则产物（化神「初触法则」后解锁）
第 4 阶  仙法   —— 仙元驱动（真仙后解锁）
```

| 阶 | 名称 | 性质 | 解锁 | 消耗 |
|---|------|------|------|------|
| 1 | **功法** | 被动，提升基础面板 | 炼气起（引气入体后才有资格修法） | 无（装在身上即生效） |
| 2 | **武技** | 主动技能，物理伤害 | 凡人即可学（拳脚刀剑是凡人的本事） | 冷却为主，不耗灵力 |
| 2 | **法术** | 主动技能，法术/元素伤害 | 炼气起（需要灵力驱动） | 灵力（mana）+ 冷却 |
| 3 | **神通** | 高阶技能/被动，法则产物 | **化神**（初触法则） | 高耗灵力，长冷却 |
| 4 | **仙法** | 顶级技能 | **真仙**（飞升后） | 仙元 |

设计意图：

- **功法管"底子"，技能管"招式"**——功法是日积月累的根基（面板），武技/法术是临场发挥的手段（按键）
- **武技是凡人的路，法术是修士的路**——凡人期只有武技可用；引气入体后法术线才打开，呼应"灵根显现"
- **神通绑定法则**——化神突破事件是"初触法则"，神通就是法则的具象化，不是"更强的法术"而是"规则级手段"
- **仙法是飞升后的内容**——与仙阶体系（仙元/天庭/法天象地）同步展开，本作先留框架

## 二、功法（被动基础数值）

### 两系分立

| 系 | 着重提升 | 倾向玩法 |
|---|----------|----------|
| **炼体功法** | 生命上限、防御、物理攻击、霸体/抗击退 | 近战硬碰（呼应元婴分叉「肉身成圣」） |
| **练气功法** | 灵力上限、灵力回复、法术强度、移动/攻击速度 | 法术、机动（呼应「元神修炼」） |

### 规则（用户口述，已敲定主干）

- **最多同时修炼两门：一门炼体 + 一门练气**；也可以只修炼一门
- 功法作为**基础数值的提升**使用（乘区叠在境界系数之上，见第六节数值口径）

### 细则提案（草案，待敲定）

- **功法有品级**：黄 / 玄 / 地 / 天 四品（数值幅度差异；天品稀有）
- **功法有层数**：1~9 层，层数提升加成幅度
- **修炼进度**（不与修为经验抢资源，各系行为喂养熟练度，**已敲定：分系喂养但不偏科**）：
  - 行为给**两系都加**熟练，但有主次偏向——炼体行为主养炼体、少量滋养练气，反之亦然（不完全偏科）
  - 炼体行为：承受伤害、近战击杀 → 炼体 +100% / 练气 +20%（比例草案）
  - 练气行为：打坐、施放法术、法术击杀 → 练气 +100% / 炼体 +20%（比例草案）
  - 设定含义：锤炼肉身时气血自然会带动气机，吐纳练气时也会间接滋养体魄——偏科有优势，但不至于另一系完全荒废
  - 熟练满 → 升层；层数上限由品级决定（黄 3 层 / 玄 5 层 / 地 7 层 / 天 9 层？）
- **切换代价（已敲定）**：换功法**保留旧功法熟练度**（回去接着修），不惩罚尝试——但要拿全两系加成就得双修，时间成本天然限制
- **获取途径**：敌人掉落（炼体系多出自体修妖兽）、商店、机缘事件、洞天秘藏（与 dongtian.md 联动）
- **数据驱动**：每门功法一个 `.tres`（名称/系别/品级/每层加成表），C++ 只读

### 与元婴分叉的关系

元婴~炼虚的「肉身成圣 vs 元神修炼」分叉（cultivation-realms.md 第一节）与功法双系是**同一倾向的两个表达**：分叉给一次性的大幅度倾斜，功法给可持续的日常积累。合体境「形神合一」时两系功法获得一次补差奖励（草案）。

## 三、武技与法术（技能）

### 武技（物理伤害）

- **性质**：招式技巧——三连斩强化、突进斩、升龙击、格挡反击等
- **消耗**：不耗灵力，**冷却驱动**（凡人的拳脚不需要灵根）
- **伤害类型**：物理（吃敌人的防御）
- **槽位**：初始 1 槽，筑基 +1，化神 +1（草案）
- **获取**：凡人期武学师傅/掉落/商店；高阶武技出自体修传承

### 法术（法术/元素伤害）

- **性质**：灵力外放成形——火弹、冰锥、雷符、御剑术等
- **消耗**：**灵力（mana）+ 冷却**（现有灵力池的第一个正经消费者）
- **伤害类型**：法术 或 元素（五行，见第五节）
- **解锁**：炼气起
- **槽位**：初始 1 槽，金丹 +1，化神 +1（草案）
- **获取**：功法典籍掉落、宗门/洞天、机缘

### 键位（已敲定：DNF 式）

- **移动 = 方向键**（↑↓←→，小键盘旁边的独立方向键，符合直觉——不是数字键）
- **其余按键全部作为技能槽/动作槽**（DNF 式），方便后续无限拓展：
  - 普攻 / 跳跃 / 冲刺 / 交互也占用其中固定键（草案：X 普攻 / C 跳 / Z 冲刺 / Space 交互？——具体映射实施时定）
  - 武技槽、法术槽平铺在字母区（A S D F G / Q W E R T…）
- **B = 切换法宝面板**：按 B 后技能键整页切换为法宝页（见第八节）；同一机制后续可扩展武技/法术多页
- 现有 WASD/J/K/L/E/F/I/Q 映射届时整体迁移（含教程/提示文案）

### 能力页面（DNF 式技能树，已敲定方向）

ESC 多页菜单中包含一个**巨大的能力页面**：把所有通过条件解锁的能力（境界能力、功法被动、武技/法术/神通/仙法、法宝祭出）汇总成一棵**庞大技能树**：

- **主动 / 被动分区**（DNF 技能树式）
- 每个节点显示：图标/名称、解锁条件（境界/事件/前置能力）、当前状态（已解锁/可解锁/未解锁）
- 与 AbilityManager（境界门控能力，已有）打通：现有纳戒/飞行/云游等全部入树
- v1 先做**只读总览**（列表/网格 + 锁定状态 + 解锁条件提示），树形连线/拖拽装配后续再做

### 与基础攻击的关系

- J 基础攻击 + 连击（ComboChain）**保留**，是永远可用的保底手段
- 武技是"带冷却的强化招式"，不是替代普攻——类似 Hollow Knight 的骨钉技艺
- 武技/法术数据结构统一为 `Skill`（id/类型/伤害类型/元素/消耗/冷却/效果脚本位），武技与法术只是 `skill_type` 之分——**为神通/仙法复用同一套数据**（第 3、4 阶只是解锁条件和消耗源不同）

### 技能槽机制分层（v1 从简，进阶已记录暂缓）

| 层 | 机制 | 状态 |
|---|------|------|
| L1 | **单技能槽**：一键绑一个技能 | v1 实施 |
| L2 | **翻页**：B 键整页切换（战斗页 ↔ 法宝页），页机制通用 | 已敲定，随法宝系统实施 |
| L3 | **连段绑定**：一键绑一串操作，逐按推进 | **暂缓**——机制复杂，等技能数量多了再做（见下） |

**L3 连段绑定（后续方向，已记录暂不实施）**：

DNF 式技能链——一个键按顺序绑定一系列操作，每按一次推进一段：

```
示例：键 A 绑定 [火球术 → 火焰屏障 → 冲刺斩]
  第 1 次按 A = 火球术（法术）
  第 2 次按 A = 火焰屏障（法术）
  第 3 次按 A = 冲刺斩（武技）
  链尾后回卷 or 停在尾段（待定）
```

- **跨类型混编是核心卖点**：链的每一格可以是武技/法术/法宝祭出任意类型——把武艺、法宝、法术融合进一条操作链，比单槽+翻页的表达力高一个量级
- 与 L2 翻页**不冲突可叠加**：翻页解决"装不下"（收藏/管理维度），连段解决"按得爽"（输出循环维度）；玩家可以翻页找喜欢的技能/法宝，再把常用组合编成连段
- 数据形态（预想）：技能槽位从 `skill_id` 升级为 `chain = [skill_id, ...]` + 每格条件（冷却独立计算？段间窗口时限？走火入魔式失败惩罚？——届时细化）
- **暂缓原因**：每格独立的冷却/消耗/打断/回卷规则 + UI 提示（当前段高亮）实现复杂，v1 技能数量还少，单槽足够；**技能槽数据结构预留 chain 扩展位**

## 四、神通（法则产物）

- **解锁**：化神境（突破事件「初触法则」后，法则系统开启）
- **性质**：规则级手段，不再是"放一团火"而是"令此地如何"——位移、控制、领域、变身
- **消耗（已敲定：独立能量条）**：化神突破后解锁**「法则之力」能量条**，与灵力池分离——神通只耗法则之力，不耗灵力
  - 上限与回复：突破时获得基础上限（如 100），缓慢自动回复 + 战斗行为回复（比例草案，HUD 加第四条短条）
  - 设定含义：法则是"悟"出来的力量，不是丹田灵力所能驱动——突破化神的那一刻才第一次感受到这条能量
- **槽位**：神通槽 ×1 起，炼虚/合体各 +1（草案）

### 法则与神通对照（草案池）

| 法则 | 神通示例 | 效果草案 |
|------|----------|----------|
| 力之法则 | 崩山劲 | 下一次攻击巨额物理伤害+破防 |
| 空间法则 | 缩地成寸 | 长距离瞬移（探索门控：穿某些窄缝） |
| 金之法则 | 金刚不坏 | 短时无敌+霸体（硬抗流） |
| 火之法则 | 三昧真火 | 持续元素火焰，烧穿凡火免疫 |
| 风之法则 | 驭风而行 | 飞行强化/罡风护体 |
| 变化法则 | 七十二变·残 | 变身躲灾（呼应原著躲三灾之术，渡劫「躲避过法」钩子） |

> 神通同时是 **Metroidvania 门控工具**（缩地成寸穿缝、金刚不坏过岩浆），与能力解锁表对齐。

## 六、伤害类型（已敲定主干）

```
伤害
├── 物理伤害 —— 普攻、武技；被「防御」减免
├── 法术伤害 —— 无属性法术；被「法术抗性」减免
└── 元素伤害 —— 五行起步，后续拓展
     └── 金 / 木 / 水 / 火 / 土（后续：雷、风、冰、毒…）
```

### 规则（用户口述 + 推论）

- **三大类**：物理 / 法术 / 元素
- **元素即五行起步**（金木水火土），**后续再拓展其他元素**（雷/风/冰/毒等）——数据结构预留扩展位
- 每次伤害带 `(大类, 元素)` 二元组：如火弹 = (元素, 火)，无属性灵压 = (法术, 无)，三连斩 = (物理, 无)

### 减伤模型（草案）

| 防御面 | 减免对象 | 来源 |
|--------|----------|------|
| 防御（现有 defense） | 物理 | 装备护甲、炼体功法、境界 |
| 法术抗性（新） | 法术 | 练气功法、饰品、境界 |
| 元素抗性 ×5（新） | 对应元素 | 丹药、法宝、特定功法、Boss 掉落 |

- **渡劫钩子**：渡劫成功免疫凡间雷/火/风（cultivation-realms.md 已定）→ 落地为 雷/风 = 拓展元素抗性 100%，火 = 五行火抗性 100%（阴火/赑风属 Tribulation 独立枚举，**不进元素系统**，避免混淆——既定代码要求）
- **五行生克（已敲定：v1 只做增伤）**：金克木 / 木克土 / 土克水 / 水克火 / 火克金——命中**被克制**元素的敌人时增伤（+25% 草案）；v1 不做减伤/无效化/相生回复，数据结构留扩展位
- **伤害结算统一封装（已敲定）**：所有伤害走一个 **`DamageCalculator`** 类——输入（攻击方面板/伤害类别/元素，防御方防御/法抗/元素抗），输出最终伤害；减伤、生克、法宝系数、后续暴击/穿透等新机制**都只往这一个类里加**，HitBox/take_damage 只负责调用

### 对现有代码的影响面（同步时）

- `HitBox` 增加 `damage_category` + `element` 字段
- `take_damage` 走统一减伤管线（防御/法抗/元素抗）
- 敌人配置增加抗性表（.tres 迁移候选）

## 八、法宝系统（本命法宝已敲定，落地细则）

cultivation-realms.md 第八节已定：本命法宝（120%→150%→觉醒 200%）+ 次要法宝（100%→120%→150%），渡劫只带本命。

落地口径（法宝面板切换已敲定，其余草案）：

- **法宝 ≠ 装备**：装备是"穿戴的物件"，法宝是"祭炼的宝物"——**独立法宝栏**，不占装备三槽
- **法宝威力系数**作用于：祭出攻击的伤害 或 常驻被动加成（每件法宝明确是攻击型/辅助型）
- **法宝栏位**：飞升前 = 本命 ×1 + 次要 ×2（纳戒容量无关）；飞升后次要栏扩展（+2，草案）
- **祭出（主动）**：攻击型法宝可祭出作战——本质是**一件法宝 = 一个特殊技能**（复用 Skill 管线，消耗灵力/仙元），如 飞剑（已有物品，筑基飞行道具→可升级为法宝）、宝塔、葫芦
- **法宝面板（已敲定：B 键切换页）**：后期法宝一大堆——按 **B** 后整页技能键切换为**法宝页**（技能键全部变为法宝快捷键），再按 B 切回战斗页；同一"切页"机制后续可直接扩展到武技/法术多页，管理非常多的技能
- **本命法宝祭炼**：择一件法宝定为本命（飞升前可换一次）；温养进度随战斗/时间推进；渡劫觉醒 +200%
- **获取**：机缘事件、洞天秘藏、Boss 掉落、功德商店（大乘）

## 九、数值叠乘口径（草案，防膨胀的关键）

```
最终攻击 = 基础攻击(角色等级基准)
         × 境界系数(现有)
         × (1 + 功法加成)        ← 炼体/练气功法
         × (1 + 装备加成)        ← 三槽装备
         × 法宝威力系数(若祭出)   ← 本命 1.2~2.0 / 次要 1.0~1.5
         × 技能倍率(武技/法术/神通各自)
```

- 功法与装备**加法合并进各自括号**（多门同类只取一门，天然限 1+1），其余**乘法分区**——膨胀可控
- 防御侧同理：防御 / 法抗 / 元素抗三线分别计算

## 十、数据模型草案（供定稿后同步代码，暂不改代码）

```cpp
// ---- 伤害类型 ----

enum Element {                  // 五行起步，预留扩展（雷/风/冰/毒…）
```
