# 美术素材管线（AI 生成）— plan

**日期**: 2026-08-13
**状态**: 仅规划，未实现。当前游戏 100% 程序化绘制（Polygon2D/ColorRect，无任何外部贴图），
后续接入实际素材时启用本管线。

## 0. 决策点先定：风格

风格决定整套渲染配置，必须最先定：

- **像素风** → 保持现状：Nearest 滤镜 + 480×270 内部画布 + 整数倍缩放。素材按真像素 1:1 导出。
- **高清手绘风** → 改配置：滤镜 Nearest→Linear、`content_scale_size` 提高（960×540 起）、
  素材用高清位图。此时「分辨率」才真正开始影响纹理清晰度。

**倾向**：若坚持像素风 → 用像素专用链路；若图省事用通用 LLM 生图 → 大概率出手绘风，
需同步改渲染配置。二选一，不要混。

## 1. 格式标准

统一 **PNG**（无损、带 alpha、Godot 直接导入、零歧义）。AI 源 + 引擎导入都用它。

| 资产类型 | 格式 |
|---|---|
| 角色/敌人/道具精灵（需透明） | PNG |
| 动画帧 | PNG 单帧（先单帧跑通，量大再打包 spritesheet 图集） |
| 大背景/远景层 | PNG 或无损 WebP（repo 体积敏感时才上 WebP） |
| UI/图标 | PNG |

**明确不用**：
- ❌ JPEG —— 有损 + 无透明，精灵直接废。
- ❌ SVG —— AI 出的 SVG 对像素/手绘不友好；Godot 导入 SVG 本质仍光栅化成纹理，绕一圈不可控。
- ❌ DDS/KTX2 —— GPU 压缩纹理是发布期优化，不是制作源格式。

## 2. Godot 导入设置（像素风关键，勿用默认）

- Filter = **Nearest**（项目已全局 nearest，单个纹理导入预设仍需确认）
- **关 Mipmaps / 关 Filter**（像素图生成 mipmap 会糊 + 摩尔纹）
- 压缩 = **Lossless**（别用 VRAM 有损压缩毁像素）
- 不缩放 / 保持原始尺寸；禁用 "Detect 3D"

## 3. AI 生成链路与分工

### 现状：两个模型

- **DeepSeek**（纯文本，无多模态）—— 本仓库代码/配置主力（即当前编码 agent）。
- **Kimi**（多模态，有额度时可用）—— 定位见下。

### Kimi 的定位：**看 > 画**

对游戏素材，「看」（视觉理解）的价值高于「画」（生成）的价值，尤其像素风：

- **通用 LLM 生图（含 Kimi）对「干净像素 + 固定调色板 + 多帧动画一致性」都很弱**——
  能出一张漂亮的单图，但出「同角色多朝向/多帧、透明边、像素网格对齐」的 sprite 序列很吃力。
- Kimi 的多模态**审图**才是不可替代的：喂生成结果给它 → 挑瑕疵、查风格漂移、描述怎么改。
  这一步 DeepSeek 做不了（看不了图）。

### 分工表

| 环节 | 工具 | 说明 |
|---|---|---|
| 代码/配置/数据 | **DeepSeek**（本仓库） | 现役 |
| 审图/一致性校验/修图反馈 | **Kimi**（多模态） | 额度优先花在这里 |
| 像素素材主力 | 像素专用链路 | SD/Flux + 像素 LoRA、Aseprite、PixelLab 等 |
| 手绘风素材（若选） | Kimi / Flux / 其他图生 | 高清单图 → 抠透明 |

**结论**：Kimi 有额度时，**优先用于审图/视觉反馈**，而非直接生成像素素材；
若走手绘风，Kimi 可参与生图，但一致性仍需参考图 + 同 seed + 同 LoRA 兜底。

## 4. 生成工作流注意

- **像素风**：用能出「真·像素图」的工具，**直接按目标像素尺寸出图**。
  ⚠️ 别先生成 512×512 再缩小——糊成一片，像素颗粒全毁。
- **抠透明**：出图 → 去背景（自动抠图/PS 生成式）→ 导出带 alpha 的 PNG。精灵必须有干净透明边。
- **一致性**（AI 素材最大坑）：同角色多帧/多朝向要固定 seed + 参考图 + 同 LoRA，
  否则风格漂移。Kimi 审图正是用来抓这个漂移的。

## 5. 落地清单（真正做素材时）

1. 定像素规格表：角色格子（如 32×32）、敌人、道具、背景层分辨率。
2. 建 `assets/textures/` + 命名规范（`player_idle_01.png` / `enemy_zhuyiao_hit_00.png`）。
3. 全局纹理导入预设统一 Nearest / 无 mipmap / 无损。
4. 动画先用单帧 PNG + `AnimatedSprite2D`，帧多了再上 spritesheet 图集。
5. 审图环节接 Kimi 视觉（可选），生成侧按风格选工具。
