# 炼丹与草药系统（v1 定稿 2026-07-25）

> 衔接：丹药 = CONSUMABLE 物品（已有回春丹/聚气丹先例）；草药 = 新 MATERIAL 类物品；
> 洞天「灵药种植」（design/dongtian.md）落地后是草药的稳定来源，本系统先提供采集/掉落来源。
> 本文定稿前只改本文档，不定稿不同步代码。

## 一、定位

- **草药**是采集/掉落材料，**丹药**是草药经炼丹转化的消耗品——给修为（XP）、回血、回灵、增益 buff 一个"材料 → 成品"的生产管线
- 与击杀/打坐并列的修为获取途径（cultivation-realms.md 既定：经验获取途径 打坐/杀敌/丹药）
- 银河恶魔城式门控：高阶草药长在此前到不了的区域（飞行/缩地成寸可达），丹药品级随探索进度自然提升

## 二、草药（材料）

新物品类型 `MATERIAL`（不可使用、可堆叠），全部静态表定义（与现有 ItemDatabase 一致，后续随 OOP 抽取迁 .tres）。

| 草药 | 品级 | 获取 | 用途 |
|------|------|------|------|
| 止血草 | 凡 | 地面采集点（前期区域）、小怪掉落 | 回春丹 |
| 聚灵草 | 凡 | 采集点、小怪掉落 | 聚气丹 |
| 冰心莲 | 灵 | 高处/洞穴采集点（需跳跃/飞行） | 冰心丹（法抗/水抗） |
| 赤焰花 | 灵 | 洞穴深处（需飞行） | 赤焰丹（攻击 buff） |
| 金刚藤 | 灵 | 岩壁采集（需墙跳/飞行） | 金刚丹（防御 buff） |
| 悟道茶 | 地 | 隐藏区域（需缩地成寸） | 悟道丹（修为 XP） |
| 千年灵芝 | 地 | Boss 掉落/洞天种植 | 大还丹（大回血+修为） |

### 采集点（HerbNode）

- 世界中的发光草节点：靠近按 **E 采集**（E=使用/装备，交互语义最近的键）→ 进背包，节点枯萎
- **刷新**：游戏内时间/房间重进刷新（v1：离开房间再进即刷新；洞天种植是稳定版）
- 采集行为喂养功法：采集 = 练气行为（喂熟练 +2，量少不刷）
- **交互键统一为 X**（已定稿）：X = 普攻 + 交互合一——附近有交互物（草药/传送门）时 X 优先交互，否则普攻；以后所有交互都用 X（Space 保留为 overlay/对话推进副键）

## 三、炼丹

### 入口（已定稿）

**丹炉随身**——设定上丹炉收于纳戒/背包，随时随地可炼。
ESC 菜单新增「炼丹」页（GameMenu 第 7 页）：配方列表 → 显示所需草药/持有数 → 选定炼制。

### 配方（固定配方 v1）

| 丹药 | 材料 | 效果 | 品级 |
|------|------|------|------|
| 回春丹 | 止血草×3 | 回血 30（已有物品，改为可炼制） | 凡 |
| 聚气丹 | 聚灵草×3 | 回灵 50（已有） | 凡 |
| 冰心丹 | 冰心莲×2+聚灵草×1 | 水抗+15%，300s | 灵 |
| 赤焰丹 | 赤焰花×2+止血草×1 | 攻击+15%，300s | 灵 |
| 金刚丹 | 金刚藤×2+止血草×1 | 防御+20%，300s | 灵 |
| 悟道丹 | 悟道茶×1+聚灵草×2 | 修为 +200（直接 accumulate_energy） | 地 |
| 大还丹 | 千年灵芝×1+冰心莲×1 | 回血 50%+修为 +100 | 地 |

-  buff 类丹药落地 **BuffSystem**（roadmap 已列"食物/丹药/状态统一为 Buff"）：到期自动消失，同名刷新时间，HUD 显示小图标+剩余秒
- **数字键消耗品栏（已定稿）**：大键盘 1~6 = 消耗品快捷栏；拾取消耗品自动入栏（首个空位），按数字直接磕（绕过背包）；HUD 技能栏上方一行显示 1~6 槽（物品名首字+数量）
- 修为丹走 `accumulate_energy`（吃到境界封顶自动卡，与既有规则一致）

### 成败与丹毒（已定稿）

- **失败机制存在**：配方带成功率字段，**v1 数值全部设为 100%**（机制预留，数值先满）
- buff 同名**刷新时间不叠加**（已定稿）
- **丹毒**（预留，v1 不做）：同种丹药短期内连磕效果递减/积毒；字段在 BuffSystem 留位

### 炼丹行为与功法

- 炼制 = 练气行为：喂练气熟练（每炉 +5）——"炼丹师也是修行"
- 高品配方设境界门控：地品丹需金丹起（丹方悟性），列表中灰显并标注条件

## 四、掉落与获取汇总

- 采集点：凡级草（前期地图撒 6~8 个点）
- 小怪掉落表追加：止血草/聚灵草 低概率（DropSystem 统一入口）
- Boss：千年灵芝保底 1
- 后续：洞天种植（design/dongtian.md 已定衔接）、商店

## 五、UI

- **GameMenu 炼丹页**：配方行 = 丹药名 + 材料需求（够=亮/不够=灰）+ 效果简述 + [E] 炼制；顶部显示各草药持有数
- **采集提示**：靠近草药显示「[E] 采集 ·止血草」（复用 interaction_prompt 信号）
- **HUD buff 区**：生命条下方小行，buff 名+剩余秒（v1 纯文本）

## 六、存档

- 草药/丹药：走现有 Inventory 存档，无新字段
- Buff：存活跃 buff 列表（id+剩余秒），读档恢复
- 采集点状态：v1 不存（房间重进即刷新，存档语义一致）

## 七、实施拆分（定稿后按序执行）

1. MATERIAL 类型 + 7 种草药 + 2 种已有丹药接配方 + ItemDatabase 表
2. HerbNode 采集点（E 采集/提示/刷新）+ 地图摆点 + 掉落表追加
3. BuffSystem（计时/属性乘区接入 DamageCalculator 攻防口径/HUD 显示）
4. GameMenu 炼丹页（配方/材料校验/炼制/境界门控/功法喂养）
5. 修为丹接 accumulate_energy + 存档 buff + harness 全套
6. X 交互合一（interact+=X，攻击让位）+ 数字键消耗品栏（1~6）
