# 洞天系统（后花园）

> 状态：**待敲定**。定稿前不同步代码。

玩家专属的随身小世界。在安全之地可随时进入/退出，是战斗之外的"家"。
从"可以开辟小世界"的修为境界开始解锁。

---

## 一、概念定位

- **洞天** = 玩家开辟的独立小秘境，三界之外自成一隅（与"渡劫之地"同类空间，但归玩家所有）
- **后花园** = 洞天的初期限定形态：一块可经营的灵地，随修为提升逐步扩张、解锁功能
- **安全区属性**：洞天内无敌人、无死亡惩罚；是修炼、种植、整理装备的落脚点

## 二、解锁条件

| 方案 | 解锁境界 | 理由 |
|---|---|---|
| **A（推荐）** | **炼虚期** | 炼虚 = 炼化虚空，已有 `void_shift`（虚空挪移）能力，主题一致；13 境中第 7 境，游戏中期获得"家"，节奏合适 |
| B | 合体期 | "身合天地"更接近开辟世界，但太晚（倒数第 5 境），玩家大半流程没有家 |

- 解锁方式：境界突破到炼虚时，经**机缘事件**触发"开辟洞天"（与突破事件体系一致，事件内容待定）
- 对应新能力：`dongtian`（洞天门），由 AbilityManager 在炼虚解锁

## 三、进入 / 退出规则

- **进入条件**（全部满足）：
  1. 已解锁 `dongtian` 能力
  2. 处于**安全状态**：无敌人仇恨（无追击中的敌人）、不在战斗硬直/受击/死亡中
  3. 不在渡劫之地等特殊场景内
- **进入方式**：按 **G 键**（备选：在安全点交互进入）
- **退出**：洞天内按 G 键，**回到进入时的位置和场景**（不是固定出口）
- 进入时记录返回点；读档后若存档在洞天内，直接载入洞天

## 四、洞天内容（分期实现）

### v1 — 空洞天（本次实现范围）
- 独立场景 `scenes/rooms/dongtian.tscn`：一小块灵地 + 天空背景
- 进出切换 + 返回点恢复 + 相机约束
- 解锁门槛（炼虚）+ 安全状态检查

### v2 — 后花园
- **灵药种植**：种下种子 → 随现实/游戏时间生长 → 收获炼丹材料（与丹药系统衔接）
- **仓库**：洞天内的额外储物箱（与纳戒互补）

### v3 — 修炼福地
- **聚灵阵**：洞天内修炼速度 ×N（境界越高阵法越强）
- **时间流速**（经典修仙设定，待定）：洞内时间 ≠ 外界，修炼题材卖点，但实现成本高（全局时间管理）

### v4 — 扩张与经营
- 洞天面积/建筑随境界扩张：炼虚初辟（一隅）→ 合体拓展 → 大乘成形 → 成仙后进化为真正的**小世界**
- 药童/傀儡 NPC、装饰、灵兽栏

## 五、技术方案（v1）

- **`DongtianManager`**（`src/nodes/dongtian_manager.h/cpp`，Node，bootstrap 创建）
  - `try_enter()`：检查能力 + 安全状态 → 记录返回点 → 加载洞天场景 → 移入玩家 → 锁相机
  - `exit()`：卸载洞天 → 恢复玩家位置/场景 → 解锁相机
  - 场景生命周期管理模式复用 Portal 的经验（Portal 是固定点进出，洞天是任意安全点进出，故独立成系统）
  - 安全状态判定：遍历场景敌人，无处于 Chase/Attack 状态者即可
- **能力**：AbilityManager 新增 `dongtian`，门槛炼虚期
- **存档**：记录"是否在洞天内 + 返回点"，读档恢复
- **HUD**：进入时提示"洞天"；安全状态不满足时按 G 给出原因提示（"战斗中无法进入洞天"）
