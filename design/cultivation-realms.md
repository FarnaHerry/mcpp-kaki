## 〇、四轴模型（核心结构）

一个角色的完整仙道状态由 **四个相互独立的轴** 组成：

```
完整称号 = 修为 + 状态 + 门派 + 身份

示例：
- 太乙真仙              （真仙级，太乙门派）
- 大罗金仙              （金仙级，大罗门派，有编制）
- 混元一气上方太乙金仙   （金仙圆满，太乙门派，高阶）
- 太乙散仙              （任何修为，太乙渊源，无编制）
```

| 轴 | 取值 | 性质 |
|----|------|------|
| **修为（纵向）** | 凡尘九境 → 真仙 → 金仙 → 混元金仙 | 硬实力，不可跳级 |
| **门派（出身标签）** | 大罗 / 太乙 / 散仙 | 纯称号，无数值差异 |
| **身份（五仙，生活方式）** | 鬼仙 / 人仙 / 地仙 / 神仙 / 天仙 | 选择，非等级，与修为交叉 |
| **出身（先天/后天）** | 先天神圣 / 后天修炼 | 影响根基扎实度 |

另有 **佛门体系** 作为道门之外的平行转修路线（见第五节）。

| 2 | 筑基 | 道基初成，脱胎换骨 | 百日闭关 |
| 3 | 金丹 | 精气神凝聚，结丹于丹田 | 三花聚顶试炼 |
| 4 | 元婴 | 丹破婴生，精神不灭 | 心魔劫 |
| 5 | 化神 | 领悟法则，神游天地 | 出窍游历 |

| 9 | 渡劫 | 三灾利害（雷、火、风） | **三灾 Boss 战** |

> 渡劫成功 = 成仙，进入仙阶体系；灵力清零转化为初始仙元。

**修为经验（99 为尊 · 全局累计，已敲定）**：

古人以 9 为至尊之数。修为经验是**全局累计值，跨境界不清零**——99 是炼气圆满，100 就是筑基，999 筑基圆满，以此类推。境界由经验区间决定，但每次跨入下一区间必须通过**机缘事件**验证（经验到顶即卡在当前境界，过机缘后继续累计）。突破不再掷概率——机缘事件本身的成败决定晋级与惩罚。

| 累计经验区间 | 境界 | 圆满值 | 跨入下一境的机缘 |
|-------------|------|-------|------------------|
| 0 – 8 | 凡人 | 9 | 引气仪式 → 炼气 |
| 9 – 99 | 炼气 | 99 | 百日闭关 → 筑基 |
| 100 – 999 | 筑基 | 999 | 三花聚顶试炼 → 金丹 |
| 1,000 – 9,999 | 金丹 | 9,999 | 心魔劫 → 元婴 |
| 10,000 – 99,999 | 元婴 | 99,999 | 出窍游历 → 化神 |
| 100,000 – 999,999 | 化神 | 999,999 | 三尸劫 → 炼虚 |
| 1,000,000 – 9,999,999 | 炼虚 | 9,999,999 | 形神合一 → 合体 |
| 10,000,000 – 99,999,999 | 合体 | 99,999,999 | 积累功德/因果 → 大乘 |
| 100,000,000 – 999,999,999 | 大乘 | 999,999,999 | 天道感应 → 渡劫之地（三灾连考）→ 真仙 |

> - 显示口径："当前/上限"= 全局经验 / 当前境圆满值（如筑基中期显示 456/999）
> - **境界内分期（已敲定）**：每境经验区间平分为三 = **前期 / 中期 / 后期**，经验满 = **大圆满**（如炼气：前期 9–39、中期 40–69、后期 70–98、大圆满 99）。仙阶各境同样适用
> - **渡劫期**：大乘圆满（999,999,999）后的过渡状态，经验条转为什么（或功德/因果代替）——待定
> - 经验获取途径：打坐/杀敌/丹药，各来源速率与节奏曲线待定
> - 原"概率突破+失败保留比例"模型作废，由机缘事件取代

### 元婴分叉：肉身成圣 vs 元神修炼

**元婴期解锁元神修炼副本**，玩家在此轻度分叉（不是永久锁定）：

| 路线 | 侧重 | 倾向玩法 |
|------|------|---------|
| **肉身成圣** | 锤炼肉体（攻/防/血、近战、霸体） | 近战硬碰，杨戬式 |
| **元神修炼** | 锤炼神魂（出窍时长/神识范围/灵魂攻击） | 法术、神识、出窍流 |

规则：

- 分叉区间 = **元婴 → 化神 → 炼虚**三境（"稍微分叉"，差异可控）
- **汇合点 = 合体境「形神合一」**：分叉在此重新归一——这正呼应合体"形神无缺"的标志：哪边偏弱，合体时补哪边
- **后期补充手段**：合体后及仙阶仍有丹药/功法/机缘可补强被冷落的一侧——前期分叉影响节奏，不决定终局
- 与能力解锁的关系：元婴出窍是公共能力，元神路线强化它（时长/可攻击），肉身路线则强化肉体面板（草案，数值后定）

**仙阶经验（待定）**：两个候选——
- A. 续涨：真仙 99,999,999,999…（数字天文化，不利于显示）
- B. **九九归一**：飞升后重新起数，仙元经验改用 9 系小数字（如真仙 99,999 / 金仙 999,999 / 圆满 9,999,999 / 混元 99,999,999）——"九九归一"暗合飞升寓意，也呼应"渡劫后灵力清零转仙元"的设定（建议 B）

### 渡劫详解：三灾（赑风 · 雷灾 · 阴火）

出自《西游记》第二回菩提祖师警示悟空的"三灾利害"。原著为成仙后每五百年一灾，本作**不完全照搬**，改为渡劫飞升时的三连大难关：

| 劫难 | 名目 | 原著描述 | 关卡形式草案 |
|------|------|----------|------------|
| **雷灾** | 天雷 | 天降雷灾打你，须要明心见性预先躲避 | 弹幕/走位考验 |
| **阴火** | 火灾 | 非天火非凡火，自涌泉穴下烧起，直透泥垣宫，五脏成灰四肢皆朽 | 体内之劫：生存/持续伤害考验 |
| **赑风** | 风灾 | 非东南西北风、非和熏金朔风、非花柳松竹风，自囟门吹入六腑，过丹田穿九窍，骨肉消疏其身自解 | 神魂之劫：控制反转/幻象考验？ |

设计要点：

- **三连劫难是"自己飞升的真仙强于天生命仙"的根源**——先天真仙没挨过三灾，根基虚浮；后天渡劫者历经雷火风淬炼，仙体扎实
- **渡劫成功奖励：免疫凡间基础雷、火、风**——既是设定（三灾都扛过了，凡间元素伤不到仙体），也是 Metroidvania 能力门控：雷域/火山区/风穴等区域在渡劫后解锁
- 原著钩子：菩提授孙悟空**七十二变即为躲三灾之术**——太乙路线的变形能力可与三灾联动（待定）
- **三灾有两种过法（原著即有，标记备展开）**：**硬抗**（肉身路线倾向）与**躲避**（元神路线倾向，七十二变属此类）——元婴分叉在此接受最终检验，具体机制后续展开
- 代码要求（已定）：三灾后续用**独立枚举**包裹，渡劫劫难专用，不与伤害类型/元素系统混淆

### 渡劫地点：渡劫之地（反"打扰"套路设定）

传统小说爱写"飞升时遭人打断/暗算"，本作**反其道而行**。

**触发**：大乘圆满、突破之时 → **天道感应 → 自动传送至"渡劫之地"**（无需寻找，时机一到天地自引）。

**渡劫之地的规则**：

| 规则 | 说明 |
|------|------|
| 不在三界内，不在五行中 | 独立秘境，自成一隅（"超出三界外，不在五行中"） |
| 外人无法进入，无法感知 | 仇家、天兵、围观者统统不存在 |
| 无法带帮手 | 独自渡劫，随从/召唤物无效 |
| 无法带法宝（**除本命法宝**） | 装备栏法宝失效，唯有与神魂相炼的本命法宝可用 |
| 死就是死，没有救援 | 二元结果：生即飞升，死就是死 |

设计意义：

- 三灾关卡 = 独立秘境（单独场景，进入即锁死，直到分出生死）
- 渡劫的紧张感来自劫难本身的强度，而非外部干扰事件——关卡设计可以更纯粹地堆三灾机制
- **本命法宝**因"渡劫唯一可携"成为特殊装备位——平时培养本命法宝是渡劫准备的核心（装备系统钩子，待定细节）

### 金仙之上的特殊称号：混元一气（特殊解锁）

「混元一气上方太乙金仙」出自《西游记》原著，称号解剖：

```
混元一气   +   上方    +  太乙  +  金仙
特殊成就      程度词      门派     境界
（需通过     （金仙后期
 某种结合）   的尊称）
```

- **混元一气**：精气神混而为一，需通过**某种结合/融合**成就达成，**不是经验堆出来的**——特殊事件解锁
- **上方**：金仙后期/高阶的程度尊称
- **混元金仙**（= 金仙大圆满 + 混元一气）仍为**玩家上限**

### 称号规则

- 标准称号 = 门派 + 境界 + 期数：太乙真仙·中期、大罗金仙·大圆满
- 特殊称号 = 特殊成就 + 程度词 + 门派 + 境界：混元一气上方太乙金仙
- 特殊称号（混元一气、以及其他未来成就词）通过特定事件/条件**单独解锁**
- 实现：称号全称后期用**独立的 OOP 组合类**计算（输入 境界/期数/门派/身份/特殊成就，输出全称）——不塞进 CultivationSystem

## 三、五仙身份（生活方式，与修为交叉）

五仙是**选择**，不是**等级**。镇元子 = 地仙之祖，但修为是混元金仙级。

| 身份 | 核心特征 | 典型修为范围（后天修炼者） |
|------|----------|--------------------------|
| **鬼仙** | 死后阴灵，可夺舍 | 无 ~ 真仙 |
| **人仙** | 有修为的凡人（未成仙） | 凡人 ~ 渡劫前（凡尘阶段默认身份） |
| **地仙** | 长生住世，不飞升 | 真仙 ~ 混元金仙 |
| **神仙** | 飞升天界，有编制 | 真仙 ~ 金仙 |
| **天仙** | 天庭高层，大功大德 | 金仙 ~ 混元 |

> 仙的常规级别只有真仙/金仙两层，五仙身份与修为是**交叉关系**，上表仅为后天修炼者的典型对应，不做硬性门槛。**先天神圣不受此限**——天兵天将出生即挂"天仙"身份，但修为只是虚浮真仙（见第四节）。

## 四、先天神圣 vs 后天修炼（出身轴 · 生死簿）

### 生死簿 —— 出身的数据载体

每个生灵的**最原始数据**都记录在生死簿上：出生（先天/后天）、原身（凡人/石猴/妖兽/星宿之气…）、寿元、劫难定数。生死簿是出身轴的载体——它不问修为高低，只记"你从哪来"。

玩法钩子（草案）：
- **查生死簿**：可查看 NPC/敌人的底细（原身、出身、寿元），揭示先天天仙"虚浮"的底
- **改生死簿**：孙悟空式事件——划掉名字则脱离生死轮回（永生/免死一次/鬼仙路线开启？）
- **寿元管理**：凡尘各境寿元有限（炼气150、筑基250、金丹500、元婴2000、化神5000），寿元耗尽则死；延寿手段（丹药、人参果、改生死簿）。**簿上寿元为物种默认值，修仙增寿不同步地府**——由此产生勾魂错抓事件（详见第五节勾魂机制）

### 先天 vs 后天

| 类型 | 出身 | 特点 | 代表 |
|------|------|------|------|
| **先天神圣** | 天地开辟时存在，或天生仙胎 | 出生即仙，但修为可能虚浮 | 天兵天将、星君、各路小神 |
| **后天修炼** | 凡人/妖兽修炼成仙 | 从底层修上来，根基扎实 | 孙悟空、镇元子 |

### 天兵天将模型（"天生真仙，战斗力垃圾"）

```
出身：先天神圣，出生即在天庭，身份挂"天仙"
实际：战力 ≈ 凡尘金丹期
原因：没经历过修炼与劫难，境界虚浮
```

### 先天神圣的层级

| 层级 | 代表 | 特点 |
|------|------|------|
| 顶级 | 三清、玉帝、如来 | 先天即天尊/佛级，修为也顶级 |
| 高级 | 四大天王、哪吒、二郎神 | 先天+后天修炼，战力强悍 |
| 中级 | 二十八星宿、九曜星君 | 先天真仙，有一定修为 |
| 低级 | 天兵天将 | 先天真仙，几乎没修炼，战力垃圾 |

### 虚浮修为机制（草案）

- 先天真仙：境界显示真仙，实际战力按"虚浮"打折（具体折扣待定）
- 突破方式：必须"下凡历劫"，从头（或从某境）重修，否则永远卡在真仙
- 后天修炼者同境界碾压先天（根基扎实）

### 开局选择（玩法提案，待定）

### 勾魂机制（寿元 · 信息差 · 意识低迷）

**核心：生死簿是地府的过期数据库。**

1. **簿上寿元 = 物种默认值**：生死簿生成时按物种写入默认寿命（灵明石猴 342 年、凡人约百年、妖兽各异），出生即定
2. **修仙增寿不同步**：修炼突破后实际寿元大增，但地府簿上仍是旧数——**信息不同步是默认状态**
3. **门派差异**：
   - 大罗（正统编制）：寿数会同步地府，不被错抓
   - 太乙/散仙：地府不知道你的真实修为与寿数 → 簿上"阳寿已尽" → 成为错抓对象
4. **触发条件**（紧凑设定，还原原著醉酒被勾）：两个条件**同时满足**才触发勾魂事件——
   - 地府簿上显示阳寿已尽（按未同步的旧寿元）
   - 目标处于**意识低迷状态**：醉酒 / 濒死（HP 极低） / 昏迷 / 熟睡
5. **事件流程**：
   - 地府按簿派差——因为不知道目标真实实力，只派**低级勾魂使**（无名小鬼、黑白无常）
   - 玩家意识低迷，但**神魂可战**：灵魂出窍迎战（联动"元婴出窍"能力）
   - **反杀勾魂使** → 二选一：还阳了事（小鬼回报错抓，地府暂记一笔）；或**顺势打入地府**（开启改生死簿事件链）
   - **战败** → 魂魄被勾入地府 → 进入地府关卡（审判/逃脱/还阳）

**设计意义**：「没给地府同步」从原著趣闻升格为玩法——改生死簿 = 黑进地府系统改自己的数据。大罗/太乙的差异也从纯称号延伸出第一个实际机制分野（是否被勾魂骚扰）。

### 与其他系统的钩子

- **鬼仙身份**：受阴间规则约束，同时享有地府通行、夺舍任务线等特权
- **死亡机制（草案）**：正常死亡（非勾魂）→ 魂魄入地府 → 还阳（跑尸/损耗待定）；勾魂事件见上
- **改生死簿**：孙悟空式大闹地府事件——划掉名字 = 脱离生死轮回（永生？鬼仙路线开启？十殿连环 Boss 战？）
- **先天神圣的特权**：天仙不在生死簿管辖（孙悟空划簿前，猴属均在簿上）

## 八、法宝系统（本命法宝 —— 已敲定）

### 法宝分两级

| 级别 | 飞升前 | 成仙后 | 性质 |
|------|--------|--------|------|
| **本命法宝** | 120% → 150%（慢慢温养） | 150% → 200%（觉醒，质变） | 跟一辈子——如托塔李天王的宝塔，成仙后一直是他 |
| **次要法宝** | 100% → 120% | 120% → 150%（工具升级） | 工具，可更换 |

### 规则（已敲定）

- **温养**：本命法宝随时间/使用慢慢成长（120%→150%），与主人神魂相炼，是飞升前的核心养成线
- **飞升前有一次更换本命法宝的机会**；飞升后不可更换
- **渡劫成功 → 本命法宝觉醒质变**（150%→200%），直接提升，终身绑定
- 次要法宝随时可换；成仙后上限提升（→150%），但还是工具
- **渡劫之地只能带本命法宝**（见第一节渡劫规则）——本命法宝的强度直接决定渡劫成败

### 法宝栏位

| 阶段 | 栏位 |
|------|------|
| 飞升前 | 本命法宝 ×1 + 次要法宝若干（栏位有限） |
| 飞升后 | 解锁更多法宝栏，本命+次要任意搭配携带 |

> 百分比 = 法宝威力系数（相对基础值），具体数值口径与现有装备三槽（weapon/armor/accessory）的整合方式在代码同步时定。
