# 追加：显示设置终案（只管游戏自己的分辨率）+ 法则条移左列

## 需求演进（用户连续四条）

1. 「窗口大小不用我们设置了——调节分辨率的时候调节一下，剩下时间用户自由拉伸，不用显示这个配置选项」
   → 删「窗口大小」行（预设档+X 自定义整数倍全删）。
2. 「全屏应该是和其他游戏一样选分辨率；缩放是 FSR/DLSS 高级能力，不需要现在做」
   → 加「分辨率」行（初版=独占全屏显示模式档）；删「缩放模式」行（固定整数倍）。
3. 「也不用叫渲染比例了，直接叫分辨率即可，axb[16:9]」→ 行改名 + 格式。
4. 「分辨率这个行不用在配置页面显示了」→ 行整删 + 渲染比例自动匹配窗口比例（中间方案，已实现）。
5. **最终澄清**：「你还没理解——只显示分辨率配置行，和其他所有普通游戏一样；这个分辨率是游戏自己的
   分辨率，窗口大小用户自己设置，无论全屏/无边框/窗口，我们只是管理自己的分辨率」→ 自动匹配方案废弃。
6. **再迭代（v2 定案）**：「全屏的时候还是分辨率只有最低比例，我们直接原生支持各种分辨率即可，
   比如 1920×1080 可以直接选择，分辨率还是改为常规的全屏下影响渲染精度」
   → 分辨率行改原生分辨率档（独占全屏=显示模式/渲染精度）；内部分辨率不再给用户选，
   480 基准比例档静默自动匹配显示比例。
7. **v3**：「现在所有状态都能调节分辨率，不要有遗留的东西了」
   → 删掉窗口/无边框全屏档的灰显（「窗口自由拉伸」「无边框全屏=桌面」文案 + 灰字 + 不响应），
   分辨率行全窗口模式可调：窗口/无边框全屏=窗口尺寸（`window_set_size`）、独占全屏=显示模式。
8. **v4**：讨论后定案「16:9 固定基准，其他 4:3/3:2 也支持，只不过加黑边」
   → 删掉 5 档比例自动匹配（`ASPECT_PRESETS`/`ASPECT_NAMES`/`_aspect_idx`/`_sync_auto_aspect`），
   内部画布固定 480×270（16:9），非 16:9 由 `aspect="keep"` 居中黑边兼容（Hollow Knight/Dead Cells 式）。
9. **v5（本轮）**：「全屏好了，小窗口黑边不对——小窗口改分辨率应外部一致、不该有黑边」→ 缩放改**分数倍**；
   同轮追加「增加帧率设置」→ 设置页加「帧率」行（30/60/120/144/无限，`Engine.set_max_fps`，cfg fps_idx）。

## 终案 v5（16:9 固定基准 + 分数倍缩放 + 帧率）

- **设置页 7 行**：主音量 / 语言 / 窗口模式（3 档）/ **分辨率** / **帧率** / 保存 / 退出。
- **分辨率行 = 原生分辨率档**（常规游戏语义）：1280×720 / 1600×900 / **1920×1080（默认）** /
  2560×1440 / 3120×2080 / 3840×2160，cfg `res_idx` 持久化。**全窗口模式可调**：
  - **窗口 / 无边框全屏**：档位=窗口尺寸（`window_set_size`，设后仍可自由拉伸）。
  - **独占全屏**：档位=显示模式（`window_set_size` 原生分辨率，影响渲染精度）。
- **内部画布固定 16:9（content_scale_size = 480×270）**：非 16:9（16:10/3:2/4:3/21:9）
  由 `aspect="keep"` 居中黑边兼容（Hollow Knight/Dead Cells 式锁定 16:9）。
  **删掉了 5 档比例自动匹配那套**（`ASPECT_PRESETS`/`ASPECT_NAMES`/`_aspect_idx`/`_sync_auto_aspect`），
  不再延伸视野、不再逐帧同步比例。
- 缩放固定**分数倍**（fractional）：窗口/全屏填满无黑边（窗口尺寸=所选分辨率外部一致）；
  非 16:9 比例仍由 aspect=keep 居中黑边。
- **帧率行**：上限档 30/60/120/144/无限（`Engine.set_max_fps`，0=不锁帧），cfg `fps_idx` 持久化。
- cfg [display] = window_mode + res_idx（旧键 resolution_idx/custom_w/custom_h/aspect_idx/scale_mode
  不再读取，存档重写自动消失）。
