## 主线修复

### DropSystem 掉落挂点（#72，三个 agent 独立撞出）

`spawn_drop` 原来一律挂 DropSystem 父节点（洲场景根），而 ItemPickup 设计上「跨父节点不磁吸/不拾取」（防洞天/房间误拾主场景掉落）→ 房间秘境内击杀 Boss，掉落物留在房间外世界坐标，玩家永远捡不到。

**修法**：`spawn_drop` 改挂**玩家当前父节点**（房间内击杀→挂进房间同层；找不到玩家退回场景根）。房间场景挂根且原点位移为 0，世界坐标=房间本地坐标，无需坐标换算。

test_di_xin_huo_ku.gd 原为旧行为写的「出窟再拾」两拍流程同步改为宫内直接拾取。

### test_tribulation_v2 掛机掉血断言

渡劫三灾全走 `take_damage_typed` → 每次受击 `feed_path(0, 1.0)` 养肉身（硬抗道，设计内）。挂机窗口途中肉身升 1 级：+3% 生命上限**并回填**（realm9 ≈ +60 HP），把首尾净额对比掩盖成「回血」。断言改为**逐帧采样掉血次数**（dips≥1 或净额下降），3 连跑稳定。
